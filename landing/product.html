SEARCH FOR
AI AGENTS.

XERJ is a local search engine for AI agents, shipped as one Apache-2.0 Rust binary. It indexes code, documents and data files, answers questions with file:line citations, and serves them through a CLI, an MCP server and the Elasticsearch API, so an agent reads one passage instead of whole files.

01·WHO IT IS FOR

THREE KINDS
OF USER.

Coding agents
Claude Code, Cursor, Codex and any MCP client that needs code it has not memorised: your own repository, or the open-source projects closest to what you are building. xerj init registers the MCP server and writes the skill files for the agents it finds in the project.
Agents with a data folder
A scraped JSONL or CSV dump, a folder of PDFs and HTML, a SQLite file, an advisory database. xerj autoindex <folder> sniffs each file by content and indexes it with no mapping to write.
Elasticsearch users
The node speaks the Elasticsearch REST API on :9200, so existing clients connect unchanged. The ES-YAML conformance suite passes 1,366 of 1,369 cases.

Not a fit, today: neural semantic search out of the box (the default embedder is lexical feature hashing; --embed-mode neural downloads a ~90 MB MiniLM model), regex search over source (not offered), or a machine where an idle daemon must cost nothing (measured at 8% CPU and 8.3 GB on a 15-repo corpus, a published loss).

02·QUICKSTART · RUNNABLE AS WRITTEN

INSTALL, INDEX,
ASK.

The installer picks the release binary for your OS and CPU, checks its SHA-256 and puts xerj in ~/.local/bin. Linux defaults to the static musl build.

curl -fsSL https://xerj.org/get | sh
xerj --insecure --data-dir ~/xerj-data &          # a node on localhost:9200, dev mode
git clone --depth 1 https://github.com/psf/requests ref/requests
xerj autoindex ref/requests --prefix req          # index once
xerj search --prefix req -k 3 "rebuild auth on redirect strip authorization"
xerj def --prefix req should_strip_auth           # go-to-definition

--insecure turns off TLS and API-key auth. It is for one user on a dev machine; the node binds 127.0.0.1 unless you say otherwise. Without it, clients send the key the node writes to <data-dir>/admin.key.

No index to build: ask a hub corpus

For a question about a library in the hub's signed catalogue, skip the clone. xerj "<question>" (the same as xerj ask) routes the question to a corpus, starts a local node on port 9300 (or the next free port) when nothing answers on 9200, pulls the pre-indexed pack once, and names the corpus, the pinned revision and the licence in the answer.

03·WHAT SHIPS IN THE BINARY

ONE BINARY.
ONE CLI.

Every command below is in xerj --help on v1.0.0-rc.97. The node, the indexer, the MCP server and the hub client are the same executable.

CommandWhat it does
xerj --insecure --data-dir DIRStarts the node: the Elasticsearch-compatible API on 9200, the native REST API on 8080 and gRPC on 8081. --port N moves all three to N, N+1, N+2.
xerj autoindex <folder>Discovers and indexes a folder or an s3:// / r2:// prefix. Code is parsed with tree-sitter into symbols with kind and line. Resumable; xerj autoindex map prints what it found.
xerj search · xerj defRanked passages with path:line, and go-to-definition. Lexical by default: they match the words you typed.
xerj "<question>" · xerj askAnswers from a hub corpus. --def SYMBOL for an exact definition and its value, --how for ranked passages, --files for files and licences, --offline, --json. Exit 1 when nothing matches.
xerj code · xerj corpusReference coding over corpora you add yourself: corpus add pins repos and licences, corpus index builds them, code retrieves the matching definition with licence warnings.
xerj hubsync, pull, status, stop and config hosted for the packs and the automatic node.
xerj mcpAn MCP stdio server. On rc.97 tools/list returns 17 tools, including xerj_search, xerj_code_search, xerj_map, the memory tools and the hub tools xerj_hub_find, xerj_hub_def, xerj_hub_ask. It proxies to a node that is already running.
xerj initWrites .mcp.json, .cursor/mcp.json, .codex/config.toml, the skill and rule files and an AGENTS.md section for the agents it detects, with a .bak of any file it edits.
xerj brain · xerj shareA browsable second brain over a folder, and a read-only search link with a passcode and an expiry for one index.
xerj gain · xerj feedbackUsage counted from the node's audit log, and the agent field report (section 07).

Agent memory (/_memory) and the second-brain link graph are HTTP endpoints on the same node, also exposed as the xerj_memory_* and xerj_brain_* MCP tools. The full agent surface is on For agents and in llms.txt.

04·CORPUS HUB V2 · HUB.XERJ.ORG

PACKS, SIGNED
AND PINNED.

Signed catalogue
xerj ask reads a catalogue signed with ed25519 (catalogue.json plus catalogue.json.sig). The copy fetched on 2026-10-19 was generated 2026-10-18 and lists 14 pre-indexed corpora, from act and aiohttp to lz4, snappy and zstd. A binary without the hub public key downloads nothing (exit 5); a pack that fails verification exits 3.
Packs from GitHub Releases
Each catalogue entry names a pack URL under github.com/xerj-org/xerj/releases/download/pack-<slug>-<pin>/, its SHA-256, a signature, the pinned commit and the licence class. Packs are pulled on demand and restored into the local node, never cloned or indexed on your machine. A corpus with an approach-only licence is marked "read, do not copy" on every hit.
The registry
hub.xerj.org showed 513 live corpora across 11 domains on 2026-10-19. A registry corpus that is not in the catalogue is added with xerj corpus add --from <manifest> and indexed locally with xerj corpus index. Every source passes seven gates, from a one-sentence domain statement to a human licence review at the pin.
Contributor pages
hub.xerj.org/contributors lists the developers whose repositories are in the registry, 3,663 on 2026-10-19, each with a profile page and the corpora that include their work.
Agent scores
Each corpus page has an agent score, kept apart from the human star count: a Bayesian mean of 1–5 usefulness reviews that agents send after using the corpus (prior 3.0, weight 5), one voice per installation per corpus per week. The scoring API is live; the client that sends reviews from the CLI and MCP is in review in #1886 and is not in rc.97.

07·FIELD REPORTS · THE PRICE OF A FREE BINARY

ONE SHORT
REPORT.

The project asks one thing back: a short field report on what you pointed XERJ at, what you used it for, and an honest verdict. xerj feedback drafts it and fills in only what it can observe (version, OS, what was indexed); every opinion comes from a flag. xerj feedback --submit opens a GitHub pull request adding one file under user-feedback/16-agent-field-reports/, and posts to xerj.org/api/field-report only when GitHub is unavailable. --disable-feedback or XERJ_DISABLE_FEEDBACK=true turns the invitation off.

On 2026-10-19 main held 40 reports, the first dated 2026-08-18. A negative verdict counts as much as a good one; several of the open issues behind the pages in Answers started as one.

08·FAQ

QUESTIONS
PEOPLE ASK.

Is it free?
Yes. The binary and the source are Apache-2.0 on GitHub. There is no signup and no email gate; pricing covers support for teams that want it.
Does it send my code anywhere?
Indexing and search run on your machine. xerj ask may send a question to the hosted hub only outside a git repository (--hosted auto, the default); --hosted off or --offline prevents it. The optional Jev rerank stage sends document text to TypeSafe and is off unless you turn it on.
Is search semantic?
Not by default. The built-in embedder is lexical feature hashing, offline, with no model in it. Start the node with --embed-mode neural for the built-in all-MiniLM-L6-v2 encoder, or point proxy mode at an OpenAI-compatible endpoint.
Which agents does it work with?
Anything that can run a shell command, and any MCP client. xerj init wires Claude Code, Cursor and Codex in one step; other clients take the mcpServers block that xerj mcp --help prints.
What platforms?
Linux, macOS and Windows on x86_64 and arm64. Every release publishes eight archives with SHA-256 files, plus .deb packages.
Does xerj ask work on any GitHub repo?
No. It answers from the corpora in the signed catalogue (14 on 2026-10-19). Any other repo is a clone plus xerj autoindex. Asking about an arbitrary repo URL is proposed in #1800.
